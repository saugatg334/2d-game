# 🇳🇵 Nepali Racer 🚗

A 2D hill-climbing racing game inspired by Nepal.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Phaser.js 3
- Vite

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Game Features

- 👤 Character Selection
- 🚗 Vehicle Selection
- 🗺️ Stage Selection
- 🛒 Shop System
- ⚙️ Settings
- 💾 Save System
